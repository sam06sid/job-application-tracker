This is a C++ program that tracks job applications using data structures: linked list, hash table, binary search tree, min-heap, stack, queue, graph (BFS), recursion, merge sort and binary search.
A small Python file adds a browser-based interface on top of the C++ program.

Features
- Add, display, update and undo applications
- Search by company (hash table, binary search)
- View deadlines (BST) and urgency ranking (min-heap)
- Interview queue and preparation advice
- Company connections and BFS traversal
- Field-based job recommendations, deadline alerts and analytics

How to run
1. Compile 'JobApplicationaddedfeatures.cpp' in Dev C++
2. Console version: run the compiled program.
3. Browser version: put 'job_tracker_app.py' in the same folder as the
   compiled program and run:
   py job_tracker_app.py
   A browser tab opens with the interface.

Requirements
- C++ compiler (Dev C++ or g++)
- Python 3 (only for the browser interface, no extra packages)
